
🔢 Group 1: Basic Arithmetic & Modulo Logic

These questions teach you how to isolate digits, work with remainders, and handle basic conditional statements.
1. Even or Odd: Write a program to check if a given integer is even or odd without using complex library functions.
2. Divisibility Check: Check if a number is completely divisible by both 3 and 5.
3. Leap Year Finder: Determine if a given year is a leap year (requires chaining multiple if-else rules).
4. Sum of Digits: Given a number (e.g., 1234), find the sum of all its individual digits (1 + 2 + 3 + 4 = 10).
5. Reverse an Integer: Given a number like 456, reverse it to look like 654 using purely arithmetic operators (not strings).

🔄 Group 2: Loops & Sequences

These questions show you how to generate counts, accumulate totals, and handle iterative processes.
6. Sum of N Numbers: Calculate the sum of the first N natural numbers (e.g., if N = 5, compute 1 + 2 + 3 + 4 + 5).
7. Factorial Generation: Find the factorial of a given number N (e.g., 5! = 5 × 4 × 3 × 2 × 1).
8. Fibonacci Sequence: Print the first N numbers in the Fibonacci sequence (0, 1, 1, 2, 3, 5, 8...).
9. Count Multiples: Count how many numbers between 1 and N are multiples of a specific number X.
10. Power of a Number: Compute \(X\) raised to the power of \(Y\) (\(X^{Y}\)) using a manual loop instead of standard power methods.

🧠 Group 3: Factors, Primes & Searching

These questions build your algorithmic thinking, helping you understand how to write efficient search boundaries.
11. Find Factors: Print all the factors/divisors of a given integer (numbers that divide it perfectly).
12. Prime Number Check: Determine if a given number is a prime number (only divisible by 1 and itself).
13. Perfect Number: A perfect number equals the sum of its proper divisors (excluding itself). Check if a number is perfect (e.g., 6 = 1 + 2 + 3).
14. Armstrong Number: Check if an \(n\)-digit number is equal to the sum of its digits raised to the power of \(n\) (e.g., \(153 = 1^3 + 5^3 + 3^3\)).
15. Integer Square Root: Given a non-negative integer X, find its square root rounded down to the nearest whole integer without using decimal approximations or built-in formulas
